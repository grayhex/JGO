# MGO platform covers

Four standalone vector square covers for game placeholders and platform categories.

- `java-j2me.svg` — Java ME / J2ME, Sony Ericsson K750i
- `n-gage.svg` — original N-Gage, Nokia N-Gage Classic
- `n-gage-2.svg` — N-Gage 2.0, Nokia N81
- `symbian-s60-3rd.svg` — S60 3rd Edition, Nokia N95

All SVG assets are self-contained: pure paths, vector fills, gradients, and strokes. No embedded raster images, external fonts, JS, CSS or external resources. The accompanying PNG files are 720px convenience exports. ViewBox is 360 × 360.

Background is opaque. Use as game cover art or platform placeholder; aspect ratio is 1:1.

Nokia N70 runs S60 2nd Edition FP3, so a Nokia N95 was used for S60 3rd Edition to avoid misleading artwork.
