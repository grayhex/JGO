Подключи пять скинов в J2ME Web. Ассеты: `apps/web/public/phones/<id>/`; контракт: `apps/web/public/phones/README.md`, параметры: `config.json`. Сделай React `PhoneSkin` и переключатель моделей, отдельно от профиля/разрешения эмуляции.

Обязательно два режима для каждого телефона: `views.full` — весь корпус, `views.screen` — увеличенная верхняя часть телефона с экраном (`zoom.webp`). Используй размеры и `screenRect` выбранного вида; Canvas с настоящим framebuffer KEmulator размещай под body, optional glass сверху. Сохраняй пропорции, при несовпадении framebuffer добавляй поля. E71 — вертикальный корпус с горизонтальным дисплеем 320×240. Zoom не меняет разрешение игры и не перезапускает MIDlet.

В full-виде используй `buttons`/`hitboxes.svg` и `keyMappings`; null-функции не превращай в вымышленные коды. Поддержи pointer capture, удержание, мультитач и release на cancel/blur/смене модели/вида. В screen-виде кнопки корпуса отсутствуют: оставь внешнюю экранную клавиатуру, клавиатуру ПК и gamepad. Состояние ввода общее, смена вида освобождает удержание.

Добавь `/phones` для сравнения всех пяти моделей, обоих видов и отладки screen/hitboxes на светлом/тёмном фоне. Проверь масштабирование, E71 QWERTY, одновременные нажатия, отсутствие залипания и запуск реального MIDlet. Запусти `python3 tools/phones/validate_assets.py` и сборку.
