# Протокол ручного тестирования нового ядра

Готовность интерфейса не означает подтверждённую совместимость игры. Начните с [SYMBIAN_TESTING.md](SYMBIAN_TESTING.md). Ниже — шаблон для каждой проверки с настоящим EKA2L1 и собственными файлами; ROM и игры в отчёт не включаются.

| Поле | Результат тестировщика |
|---|---|
| Дата, версия JGO, EKA2L1 (из панели) | |
| Игра, версия, SHA-256 (из Game settings) | |
| Платформа: Symbian / N-Gage / N-Gage 2.0 | |
| Реальная прошивка: модель, product code, версия/ОС | |
| Источник установки: ROM/RPKG, архив или VPL/FPSX; вариант VPL, полнота комплекта, результат job | |
| Явный профиль / устройство игры / умолчание платформы / единственное устройство | |
| Выбранный скин и режим full/screen | |
| Статус перед стартом и время до первого кадра | |
| Размер кадра, цвета, letterbox, screenshot | |
| FPS в меню и игре; звук и задержка | |
| Стрелки/Select/soft keys/C/цифры; одновременно несколько кнопок | |
| Клавиатура и gamepad; release при blur/disconnect/смене вида | |
| Тач: одиночный/несколько контактов, поворот, cancel | |
| Сохраниться в игре → Stop → Start → загрузить | |
| Перезагрузка браузера → подключение к прежней сессии | |
| Пауза/возобновление; Stop во время запуска | |
| Несовместимый/отсутствующий профиль → понятный отказ, прежняя игра остаётся | |
| Итог: работает / частично / не запускается; шаги воспроизведения | |

Приложите Download Symbian diagnostics; при наличии сессии также Download diagnostics из плеера. Укажите первый неверный шаг, фактический product code и текст предупреждения. Успешный запуск в другом скине не является проверкой другой прошивки. Для N-Gage Classic/QD экран должен оставаться 176×208 внутри горизонтального корпуса; для N8 — 360×640 и одна нижняя аппаратная клавиша.
