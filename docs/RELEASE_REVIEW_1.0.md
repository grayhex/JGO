## Исправлено в этом PR

- **Безопасность:** `@fastify/static` 8 → 10 (4 advisory, из них 1 high); не более 10 неверных токенов в минуту с одного адреса, затем `429` + `Retry-After` (проверено тестом, верный токен не считается).
- **Базовое:** кнопка *Sign out* и `POST /api/auth/logout` (куки жили 30 дней без способа выйти); страница-заглушка вместо белого экрана при ошибке отрисовки (игра на сервере продолжает работать); неизвестный адрес ведёт в библиотеку, а не показывает её по чужому URL.
- **Производительность:** gzip на шлюзе для скриптов, стилей и JSON (UI 420 КБ → ~137 КБ; список игр кратно меньше); проигрыватель больше не перерисовывается при каждом нажатии кнопки геймпада.
- **Мелочи:** `404` в консоли при открытии Symbian/N-Gage-игры (запрос анализа JAR); устаревшие подписи в документации.

## Не сделано / решение за владельцем

1. **Версия** в `package.json` — `0.1.0-beta.1`. Номер 1.0.0, тег и релиз — по `docs/RELEASE.md`; я их не менял.
2. **Нативная установка (Proxmox/LXC) без шлюза** не сжимает ответы (gzip только в Docker-шлюзе). Варианты: `@fastify/compress` или nginx перед приложением.
3. **Ограничение перебора токена за шлюзом** считает по адресу шлюза (все браузеры — один адрес): оно мешает подбору, но при атаке на минуту блокирует и вход по токену для остальных (уже вошедшие по cookie не страдают). Точнее — `trustProxy` + `X-Forwarded-For` от нашего шлюза; не включал, чтобы не открыть подмену адреса при прямом доступе.
4. **Остаточные advisory (moderate)**: `glob`/`minimatch` внутри `@fastify/static` (отказ в обслуживании при разборе glob-шаблонов); MGO не использует glob-режим (`wildcard: false`), исправление апстрима ждёт. Не блокирует релиз.
5. **Не измерено:** отрисовка списка из тысяч игр в браузере (в DOM все строки, виртуализации нет; API отвечает быстро); поведение на iOS Safari и реальных Android-устройствах (touch, полноэкранный режим, звук); длительная работа (часы) одной сессии на утечки памяти.
6. **Доступность:** у страницы игры нет заголовка `h1` (название игры в обычном тексте); около 3 кнопок меньше 24 px (иконки действий в строке библиотеки) — пальцем на телефоне мелко.
7. **Symbian/N-Gage** остаются экспериментальными: игры на настоящих прошивках не проверялись (это отмечено в документации и интерфейсе), поддержка EKA1/S60 2nd в EKA2L1 слабая.
8. **Резервное копирование** `/data` (сохранения, настройки, прошивки Symbian) — только руководство (`docs/BACKUP.md`), автоматического бэкапа нет.
